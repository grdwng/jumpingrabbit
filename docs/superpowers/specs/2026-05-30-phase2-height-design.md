# 跳跳小方块 — 第二阶段设计规格

**日期**: 2026-05-30
**版本**: v1.0
**状态**: 待批准

---

## 1. 概述

第二阶段在第一阶段基础上引入**高度维度**，玩家可以在不同高度的方块间跳跃。高度跳跃需要更多策略思考，同时保留第一阶段的核心玩法。

### 与第一阶段的关系

- 继承：操作方式、奖励系统、生命值机制、通关评价
- 增强：高度维度，跳跃策略，视觉深度

---

## 2. 高度系统

### 高度层级

- **层级0（地面）**: 默认高度，初始层级
- **层级1（中层）**: 比地面高1格
- **层级2（高层）**: 比地面高2格

### 跳跃规则

| 操作 | 适用场景 | 说明 |
|------|----------|------|
| 方向键 | 高度差 ≤0（向下/同层）| 向下跳无限制，同层随便跳 |
| 方向键 + Space | 高度差 = 1（向上跳1格）| 需要同时按才能触发 |
| 方向键 + Space | 高度差 >1 | 不能跳 |

### 高度差判定

- 高度差 = 目标方块高度 - 当前位置高度
- 向下跳（差值 ≤ 0）：无限制，可跳到任意低处
- 同层跳（差值 = 0）：正常跳跃
- 向上跳（差值 = 1）：需要 Space 辅助
- 向上跳（差值 > 1）：禁止跳跃

---

## 3. 高度差跳跃

### 向下跳（逃生路线）

- **操作**: 方向键
- **规则**: 可跳到任意低于当前高度的方块
- **结果**:
  - 目标位置有方块 → 成功落地
  - 目标位置是空的 → 跳空死亡，-1命，重置关卡

### 向上跳（需要决策）

- **操作**: 方向键 + Space（同时按）
- **规则**: 只能向上跳1格高度
- **结果**:
  - 目标位置有方块 → 成功落地
  - 目标位置无方块或高度差>1 → 不能跳

### 同层跳

- **操作**: 方向键
- **规则**: 同高度或向上跳1格（同Space逻辑）

### 设计意图

- **向上跳是风险操作**: 需要同时按Space，增加决策
- **向下跳是逃生路线**: 无限制，但跳空就死
- **没有单独的救命跳跃机制**: 向下跳就是逃生选项

---

## 4. 视觉设计

### 方块高度表现

- 方块厚度 = 真实高度（1格 = 约0.5单位高度）
- 不同层级方块有明显高度差异
- 边缘有轻微倒角，更圆润卡通

### 高度视觉辅助

| 层级 | 颜色倾向 | 阴影 | 说明 |
|------|----------|------|------|
| 层级0 | 正常暖黄色 | 标准阴影 | 地面层 |
| 层级1 | 略微偏亮 | 较浅阴影 | 中层 |
| 层级2 | 明显偏亮 | 很浅/无阴影 | 高层，有悬浮感 |

### 相机设置

- 俯视角，能清晰看到高度落差
- 视角高度适中，不遮挡前方方块
- 跟随模式下能看到跳跃路径

## 5. 关卡设计

### 难度梯度

| 阶段 | 关卡 | 特点 |
|------|------|------|
| 铺垫期 | 1-5 | 高度概念引入，偶尔高低方块，主要练习向下跳 |
| 挑战期 | 6-10 | 高度跳跃成为主要路径，需要按Space |
| 冲刺期 | 11-15 | 复杂高度布局，综合所有机制 |

### 关卡结构

每关定义：
```javascript
{
  id: 21,  // 第二阶段从21开始
  name: "初见高低",
  blocks: [
    {x: 0, y: 0, z: 0, type: "start"},
    {x: 1, y: 0, z: 0, reward: "coin"},
    {x: 1, y: 1, z: 0, reward: "energy"},  // 高1格的方块
    // ...
  ],
  endPosition: {x: 4, y: 1, z: 2},
  targetCoins: 350
}
```

## 6. 状态机

### 关卡内状态

```
[等待输入]
    ↓ 按方向键 (判断高度差)
[判断: 向上跳?] → Yes → 需要同时按Space
[跳跃中] (400ms动画)
    ↓ 落地
[判断: 落方块?] → Yes → [收集奖励] → [等待输入]
    ↓ No
[判断: 有护盾?] → Yes → [消耗护盾] → [等待输入]
    ↓ No
[死亡动画] → [重置本关] → [等待输入]
```

## 7. 操作对照表

| 操作 | 输入 | 适用场景 | 结果 |
|------|------|----------|------|
| 向下跳 | 方向键 | 目标高度 < 当前 | 有方块→落地；无方块→死亡 |
| 同层跳 | 方向键 | 目标高度 = 当前 | 正常落地 |
| 向上跳 | 方向键 + Space | 目标高度 = 当前+1 | 有方块→落地；无方块→不能跳 |

### 功能验收

- [ ] 方向键控制跳跃正常
